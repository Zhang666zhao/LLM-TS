# Results

Only compact, reviewable benchmark results belong here. Full prediction arrays,
logs, checkpoints, and intermediate artifacts stay on shared storage.

Each benchmark directory should contain:

- an immutable source file or clear source-run reference;
- canonical `variable_metrics.csv` when variable results are available;
- `dataset_metrics.json` and `summary.json` generated by shared evaluation;
- provenance including the source hash and schema version.

Generated files must be reproducible from the committed source without running
model inference.
