# benchmark_v1

The [method comparison](method_comparison.md) additionally includes TimeMRA's
Weather result and the completed 49 evaluations from the seven-method
`20260926_baselines_ctx512_pred64` suite, added on 2026-09-28. These new results
are stored separately in `baselines_512_64_20260928.json`; the original importer
outputs below remain unchanged. See `baselines_512_64_20260928_audit.md` for
training regimes and the user-authorized PatchTST Electricity stop: its result
evaluates epoch 56 after 64 completed epochs, not a 30-epoch run.

This snapshot compares TS-RAG, Chronos-Bolt, and shared DLinear across seven datasets using
context length 512 and prediction length 64. It was imported from the completed
workbook in `source/`; no inference was rerun.

`variable_metrics.csv` is the canonical long-format result. The JSON files are
deterministic aggregates generated by `scripts/import_existing_results.py`.
The workbook's own `Method and checks` sheet identifies its underlying source
runs as the 20260826 TS-RAG ablation suite.

DLinear comes from `20260922_DLinear_shared_ctx512_pred64`. It is trained
separately on each dataset (`supervised_per_dataset`), whereas the other two
methods are zero-shot. The committed DLinear source results exclude checkpoints,
predictions, targets, and logs.

The importer reconciles every dataset against the workbook `Summary` sheet.
Benchmark MSE/MAE are macro averages of the seven dataset metrics. Relative
improvements in `summary.json` are reported per dataset; consumers may either
average those percentages or calculate a ratio from the macro-average metrics,
but must label which aggregation they use.
