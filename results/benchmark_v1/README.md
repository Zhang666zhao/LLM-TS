# benchmark_v1

This snapshot compares TS-RAG and Chronos-Bolt across seven datasets using
context length 512 and prediction length 64. It was imported from the completed
workbook in `source/`; no inference was rerun.

`variable_metrics.csv` is the canonical long-format result. The JSON files are
deterministic aggregates generated by `scripts/import_existing_results.py`.
The workbook's own `Method and checks` sheet identifies its underlying source
runs as the 20260826 TS-RAG ablation suite.

The importer reconciles every dataset against the workbook `Summary` sheet.
Benchmark MSE/MAE are macro averages of the seven dataset metrics. Relative
improvements in `summary.json` are reported per dataset; consumers may either
average those percentages or calculate a ratio from the macro-average metrics,
but must label which aggregation they use.
