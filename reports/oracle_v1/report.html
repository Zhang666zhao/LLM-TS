01 / RESEARCH DESIGN

四个方案，两个独立比较维度

标签定义与模型预测无关；每个变量使用自己的标签。A 与 B 的对照不同，必须分别报告。

A-L1联合预测头 × 近期变化

骨干与条件头联合训练；用未来64步相对最近64步的变化标签。

对应对照：A-zero
A-L2联合预测头 × 长期偏离

骨干与条件头联合训练；用未来64步相对历史512步的偏离标签。

对应对照：A-zero
B-L1冻结校正块 × 近期变化

冻结基线，训练共享逐变量输出校正模块；输入L1标签。

对应对照：B-zero
B-L2冻结校正块 × 长期偏离

冻结基线，训练共享逐变量输出校正模块；输入L2标签。

对应对照：B-zero
L1 = (mean(future64) − mean(recent64)) / max(std(history512), 0.001)
L2 = (mean(future64) − mean(history512)) / max(std(history512), 0.001)
z = +1 if L > 0.5; −1 if L < −0.5; otherwise 0　｜　std: ddof=0，训练集标准化尺度
历史 512 步多变量输入 → 原有骨干
→
条件头 A / 校正块 B各变量仅接入自己的离散标签
→
未来 64 步全部变量预测、监督与评估

每个数据集：5模型 × [1基线 + 2种zero对照 + 4种oracle方案] = 35配置。A/B 条件模块均使用3类标签嵌入；zero对照保留相同结构但输入固定0。未来均值、变化幅度不直接输入模型。

全变量 MSE：联合头中，标签优劣依数据集而变

A-L2 在 ETTh2、ETTm1 的平均改善大于 A-L1；其他三个数据集则 A-L1 更高。不能一概认为 L1 总是更好。

全变量 MSE：冻结校正块中，L1 更稳定

B-L1 在五个数据集的平均改善均大于 B-L2。但全变量均值改善不意味着每个通道都改善，OT 可出现退化，需单独检查。
