## 窗口、标签定义与输入边界

原始行号从 0 开始，t 为预测区间第一行。历史输入 `[t−512,t)`，真实预测目标 `[t,t+64)`。训练 t=512..8576，验证 t=8640..11456，测试 t=11520..14336，均含端点。原切分完全保留，标签复用不跨切分。

L1 为未来 64 步均值相对最近历史 64 步均值的差，L2 相对历史 512 步均值；均除以 max(历史总体标准差,0.001)，严格大于 0.5 为 +1，严格小于 −0.5 为 −1，其余为 0。阈值沿用历史 oracle 语义。

训练期 API 输入采用因果前缀 StandardScaler：对代表窗口 a，只拟合原数据 `[0,min(a,8640))`。验证/测试使用完整原训练集统计，验证输入与旧缓存逐项一致。这样早期训练输入不会使用较晚训练观测的统计量。该输入处理与旧验证方式统一在“只拟合已观察到的训练前缀”规则下；训练期数值表示随前缀增长，作为缓存版本的一部分保留。

真实标签仍按原 oracle 数据和标准化规则离线计算。独立核验全部窗口原 epsilon 未激活，并核验准备阶段各代表窗口的尺度变换不改变离散真标签；所有输入归一化参数及实际发送历史与截至当时的前缀一致。API 只接收历史数据及其统计，未来目标不进入请求。训练集标签质量是训练数据诊断，验证集用于开发；测试结果来自已冻结的配置。这些时间序列窗口和变量相关，不能将全部判断当作独立样本估计显著性。
